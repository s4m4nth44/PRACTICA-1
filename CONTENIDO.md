# Práctica 1: Salidas Digitales con PIC16F887

## Objetivo
Implementar diferentes aplicaciones utilizando salidas digitales del PIC16F887.

## Software utilizado
- MPLAB X IDE
- Compilador XC8
- Proteus 8

### Clase: Parpadeo de 4 LEDs
Se implementó un programa que hace parpadear cuatro LEDs conectados al microcontrolador.

### Actividad 1: Contador binario de 6 bits
Se desarrolló un contador binario utilizando seis salidas digitales para representar los números en formato binario.

### Actividad 2: Secuencia tipo caminata de 8 bits
Se implementó una secuencia donde un único bit activo se desplaza a través de ocho LEDs.
